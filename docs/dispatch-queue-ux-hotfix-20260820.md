# Dispatch queue UX hotfix — 2026-08-20

Correcciones verificadas para la consola de operador antes del lanzamiento:

- La vista Compacta ya contiene origen, destino, cliente, móvil, estado, tarifa y acciones; la tabla es horizontalmente desplazable cuando el ancho disponible es reducido.
- La vista Compacta incluye cancelar carrera para carreras pendientes y asignadas.
- La vista Visual debe permitir cancelar tanto carreras pendientes como asignadas. Este punto se corrige en el siguiente cambio de OperatorConsole.
- Las carreras pendientes deben permanecer visibles con origen y destino, sin obligar a abrir detalle para reconocer la llamada.
